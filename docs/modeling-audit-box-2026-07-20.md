# Аудит моделирования #12 — протокол «коробка» (2026-07-20)

**Проект:** открытый `.rvt`, вид «2 этаж» (FloorPlan, Z≈3900 мм).  
**Тестовая зона:** в стороне от корпуса `(100000, 100000)` … `(106000, 104000)` мм — элементы после теста удалены.

## Сценарий

1. `get_available_family_types` → типы стен/полов/дверей/окон.
2. 4 стены 6000×4000 мм, `typeId=11387` (`ADSK_Внутренняя_Бетон_300`), height 3000.
3. Пол `typeId=23138` (`ADSK_Пол_Условный_80`).
4. Дверь + окно с `hostWallId`.
5. Room внутри контура.
6. Негативные кейсы: стена без `typeId`; дверь без `hostWallId`.

## Корневые причины жалобы «вручную быстрее и лучше»

1. **Тип-рулетка:** нет `typeId` → первый `WallType` в проекте (здесь витраж). Тихий успех.
2. **Схема врёт:** `thickness`/`width`/`height` не меняют геометрию типа.
3. **Много round-trip:** walls → floor → door/window → room; внутри — отдельный `Transaction` на каждый элемент.
4. **Нет joins / location line / structural** — углы и чистота хуже ручного.
5. **Узлы РД** не реализованы (отдельный трек REV-40).
