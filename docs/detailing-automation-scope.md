# REV-40. Узлы: границы автоматизации и пилот на публичном эталоне

Статус: **живой пилот пройден 2026-07-21** на общем эталоне «примыкание пола к стене» (без файла заказчика).  
Подгонка под шаблон организации — после приёмки пилота / когда заказчик пришлёт 1–2 своих узла.

## 0. Scope: что ИИ умеет и не умеет (итог пилота)

**ИИ пока не умеет сам создавать узлы РД** — не выбирает конструктивное решение, не подбирает узел под конкретную стену/пол/мокрую зону, не генерирует 3D-узлы и не заменяет проектировщика на этапе «какой узел нужен и отвечает ли он нормам». Без семейств и стилей организации результат — учебная схема, а не альбом заказчика.

**Что можем автоматизировать уже сейчас** — механическое оформление, когда решение уже принято человеком или взято из эталона:

| Этап | Инструмент | Комментарий |
|------|------------|-------------|
| Чертёжный вид / фрагмент | `create_detail_view` | drafting с нуля или callout с плана вокруг элемента |
| Эскиз слоёв линиями | `create_detail_lines` | без новых `.rfa`; по `viewId` / `viewName` или активному виду |
| Подписи с выносками | `create_text_note` | работает по `viewId`, типы ADSK из проекта |
| Размеры | `create_dimensions` | толщины, зазоры — по линиям эскиза |
| 2D-детали из библиотеки | `place_detail_component` | линия разрыва, гидроизоляция и т.п., если семейство уже в проекте |
| Лист | `create_sheet` + `place_view_on_sheet` | штамп организации, размещение viewport |

**Формула для команды:**

```
Решение «какой узел» + ответственность  →  архитектор / ГИП
Эталон, .rfa, штриховки, стили линий    →  шаблон организации / библиотека заказчика
Вид, эскиз, подписи, размеры, лист       →  ИИ через MCP (чертежник-ассистент)
Финальная приёмка и выпуск               →  архитектор
```

**Где реальная экономия времени:** повтор одного и того же эталонного узла на многих листах; черновик для согласования («набросай примыкание пола М1:10»); callout с плана вокруг уже смоделированного стыка; серия листов Уз-01…Уз-N по одному сценарию.

**Не делаем в проде:** `send_code_to_revit`; генерация 3D-узлов; выдумывание конструктива «из головы» без эталона и норм из библиотеки.

## 1. Публичный эталон пилота (не от заказчика)

**Узел:** примыкание пола к стене / перегородке (сечение).  
**Источник (типовая практика РД):** ГОСТ 21.501 (выносные элементы), серия 2.140-1 «Примыкание полов», руководства по полам (зазор у стены ≥20 мм под стяжку / 4–5 мм под полимер).

**Состав слоёв (упрощённый М1:10, слева стена — справа пол):**

| # | Элемент | Типичная толщина |
|---|---------|------------------|
| 1 | Стена (вертикаль) | по типу (напр. 200 мм) |
| 2 | Плита/основание | — |
| 3 | Звуко-/гидроизоляция | тонкий слой |
| 4 | Стяжка | ~40–50 мм |
| 5 | Покрытие | ~10–20 мм |
| 6 | Зазор у стены + плинтус | ≥20 мм (стяжка) |

**Масштаб:** 1:10. **Тип вида:** `drafting` (чертёжный вид) — не зависит от 3D модели.

## 2. Пилотный инструментарий

| Инструмент | Что делает |
|---|---|
| `create_detail_view` | **callout** — фрагмент плана/разреза; **drafting** — чертёжный вид с нуля |
| `place_detail_component` | 2D-компоненты узла по имени семейства/типа |
| `create_text_note` | Текст + прямая выноска |
| `create_detail_lines` | Линии на плане **или** drafting/detail (эскиз слоёв без .rfa) |
| существующие | `create_dimensions`, `place_view_on_sheet` / `auto_layout_sheet`, `get_available_family_types` |

## 3. Сценарий пилота (публичный эталон)

1. `create_detail_view` `{ mode: "drafting", name: "Узел 1. Примыкание пола к стене", scale: 10 }`
2. Активировать вид → `create_detail_lines` — контуры стены, плиты, стяжки, покрытия, зазора (мм в плоскости вида).
3. `create_text_note` — подписи слоёв (или `create_text_notes` на drafting).
4. `create_dimensions` — толщины слоёв / зазор.
5. `create_sheet` + `place_view_on_sheet` — узел на лист.
6. (Опционально) если в проекте есть 2D detail families → `place_detail_component`.

## 4. Границы автоматизации (кратко)

| | |
|---|---|
| **ИИ (MCP)** | вид, эскиз линиями, тексты, размеры, лист, размещение готовых 2D-деталей |
| **Проектировщик** | выбор узла, новые `.rfa`, адаптация под объект, приёмка по шаблону организации |
| **Вне scope** | 3D-узлы; `send_code_to_revit` в проде; полная замена архитектора на узлах |

**Результат пилота 2026-07-21:** в проекте «Короткий блок» собран полный цикл — чертёжный вид «Узел 1. Примыкание пола к стене», эскиз, подписи, 5 размеров, линия разрыва, лист **Уз-01**. Подтверждено: инструментарий работает; без эталонов заказчика оформление остаётся учебным.
