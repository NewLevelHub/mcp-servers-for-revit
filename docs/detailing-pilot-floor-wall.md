# Пилот узла: примыкание пола к стене (публичный эталон)

Координаты в **мм** в плоскости drafting-вида (начало ≈ угол примыкания).

## Шаг 1 — вид

```json
{
  "mode": "drafting",
  "name": "Узел 1. Примыкание пола к стене",
  "scale": 10,
  "detailLevel": "Fine"
}
```

Tool: `create_detail_view`

## Шаг 2 — эскиз слоёв (`create_detail_lines`)

После активации drafting-вида:

**Стена** (вертикаль слева, толщина 200): прямоугольник  
`(0,0)–(200,0)–(200,600)–(0,600)–(0,0)`

**Плита** (горизонт):  
`(200,0)–(800,0)–(800,200)–(200,200)–(200,0)`

**Стяжка** (40 мм над плитой):  
`(220,200)–(800,200)–(800,240)–(220,240)–(220,200)`  
(отступ 20 мм от стены = деформационный зазор)

**Покрытие** (15 мм):  
`(220,240)–(800,240)–(800,255)–(220,255)–(220,240)`

## Шаг 3 — подписи

`create_text_note` / `create_text_notes` на виде, например:

- «Стена» у (50, 400)
- «Плита перекрытия» у (400, 80)
- «Стяжка» у (450, 210)
- «Покрытие» у (450, 250)
- «Зазор ≥20» у (210, 220)

## Шаг 4 — размеры

`create_dimensions` — толщина стены 200, зазор 20, стяжка 40 (по линиям эскиза).

## Шаг 5 — лист

`create_sheet` + `place_view_on_sheet` с `viewId` из шага 1.

## Примечание

Это **учебный** узел для проверки MCP, не альбом заказчика. После пилота подставляются их семейства/штриховки.
